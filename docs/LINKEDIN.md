## App Geek — Sistema Full-Stack de Inscrições para Eventos 🎃

Desenvolvi o **App Geek**, um sistema web para gerenciar inscrições em eventos utilizando **Next.js, React, TypeScript e PostgreSQL**.

O participante escaneia um **QR Code temporário**, acessa o formulário pelo celular e conclui sua inscrição. No painel administrativo, a equipe acompanha indicadores, gráficos e cadastros, controla a abertura das inscrições, exporta dados em CSV e gerencia administradores com diferentes níveis de permissão.

Entre os principais desafios técnicos estiveram a construção de APIs seguras, sessões de login no PostgreSQL, regras de negócio para evitar duplicidade, atualização dinâmica do QR e organização de um projeto full-stack pronto para deploy.
